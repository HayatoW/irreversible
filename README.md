# Irreversible

This is a portfolio/blog site built with TanStack Start. Includes:

- MDX and Markdown support
- Optimized for SEO (sitemap, robots, JSON-LD schema)
- RSS Feed
- Dynamic OG images
- Syntax highlighting
- Tailwind v4
- Vercel Speed Insights / Web Analytics
- Geist Mono font

## Demo

https://portfolio-blog-starter.vercel.app

## How to Use

You can choose from one of the following two methods to use this repository:

## Development

Install dependencies and run the TanStack Start development server:

```bash
pnpm install
pnpm dev
```

## Production

Build the app for production:

```bash
pnpm build
```

Start the production server:

```bash
pnpm start
```
