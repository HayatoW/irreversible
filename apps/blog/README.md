# Blog

Personal blog built with [Remix](https://remix.run) 3.

## Run

Requires Node.js >= 24.3.

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

Other commands:

```bash
pnpm test       # router smoke tests via `remix test`
pnpm typecheck  # tsc --noEmit
pnpm start      # production mode
```
