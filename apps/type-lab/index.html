01 / SHAPE

輪郭から描く。

フォントの曲線を細かな線分に分解し、WebGPUで内外と輪郭までの距離を計算。画像を引き伸ばさず、文字のかたちを描き直します。

02 / TYPE

複雑さを楽しむ。

同じ「鬱」でも、明朝とゴシックでは違う表情に。文字サイズや線の太さを変えて、画と画のあいだにある余白を観察してください。
