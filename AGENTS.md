# AGENTS.md

## Cursor Cloud specific instructions

This is a TanStack Start (Vite/React) portfolio/blog site ("Irreversible"). Single application, no monorepo.

### Services

| Service | Command | Port | Notes |
|---|---|---|---|
| TanStack Start Dev Server | `pnpm dev` | 3000 | The only service needed |

### Dev commands

- **Dev server**: `pnpm dev` (runs on port 3000, uses Vite)
- **Build**: `pnpm build`
- **Start**: `node .output/server/index.mjs`
- **Type check**: `npx tsc --noEmit`
- **No ESLint or test framework** is configured in this project.

### Project structure

- `app/routes/` — TanStack Router file-based routes
  - `__root.tsx` — root layout (fonts, Navbar, Footer, Analytics)
  - `index.tsx` — home page (`/`)
  - `blog.index.tsx` — blog list (`/blog`)
  - `blog.$slug.tsx` — blog post (`/blog/:slug`)
  - `og.tsx` — OG image server route (`/og?title=...`) — satori + @resvg/resvg-js
  - `rss.tsx` — RSS feed server route (`/rss`)
  - `sitemap.tsx` — sitemap server route (`/sitemap`)
- `app/blog/posts/*.mdx` — blog posts (MDX with frontmatter)
- `app/blog/utils.ts` — `getBlogPosts()`, `formatDate()` helpers (Node.js fs)
- `app/components/` — shared components
- `app/config.ts` — shared constants (baseUrl)
- `app/router.tsx` — TanStack Router config (exports `getRouter()`)
- `app/routeTree.gen.ts` — auto-generated by TanStack Router plugin (do not edit)
- `public/robots.txt` — static robots file

### Gotchas

- `app/routeTree.gen.ts` is auto-generated on `pnpm dev`. Commit it if it changes.
- Blog posts are MDX files compiled server-side using `@mdx-js/mdx` `compile()` in the route loader.
- OG images use `satori` + `@resvg/resvg-js` with a system TTF font (`/usr/share/fonts/truetype/croscore/Arimo-Bold.ttf`).
- `@resvg/resvg-js` is a native Node.js module; it's excluded from Vite `optimizeDeps` in `vite.config.ts`.
- The `@types/react` version in `package.json` (18.x) is behind the actual React version (19.x). This is intentional; `skipLibCheck: true` in `tsconfig.json` avoids type errors.
- Fonts are loaded via `@fontsource-variable/noto-sans-jp` and `@fontsource/geist-mono` CSS imports in `app/global.css`.
